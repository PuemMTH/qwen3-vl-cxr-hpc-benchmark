# AI for Research — Core Program

โฟลเดอร์นี้มีเฉพาะเนื้อหาหลักสูตรที่ใช้ทำงานจริง โดยไม่ผูกกับเว็บไซต์หรือส่วนติดต่อผู้ใช้

## เริ่มใช้งาน

เรียนตามลำดับจาก [`modules/module-01.md`](modules/module-01.md) ถึง
[`modules/module-09.md`](modules/module-09.md) แต่ละโมดูลมีแนวคิด กิจกรรม Prompt และ
Checkpoint อยู่ในไฟล์เดียว

| โมดูล | เนื้อหา |
|---|---|
| 01 | Prepare Your AI Research Workspace |
| 02 | Your First AI Research Task |
| 03 | Problem → Gap → Research Question |
| 04 | Literature Evidence |
| 05 | Research Logic |
| 06 | Experiment Design Stress Test |
| 07 | Analysis & Visualization |
| 08 | Document Production |
| 09 | Personal AI Research Workflow |

ไฟล์ใน `workbooks/` เป็นแบบฝึกที่โมดูล 5–9 ใช้งานโดยตรง ส่วน `cases/` เป็นกรณีตัวอย่าง
สำหรับผู้เรียนที่ยังไม่มีงานจริงในโมดูล 8–9

## ขอบเขตที่ตั้งใจตัดออก

- Landing page, navigation, registration, pricing และ checkout
- HTML, CSS, JavaScript, browser storage, analytics และ interactive UI
- Installer, document importer, deployment และ test scripts
- ห้องทดลองหรือ demo เสริมที่อยู่นอกเส้นทาง Module 1–9
- Template และ asset ที่มีหน้าที่ช่วย render เว็บไซต์หรือเอกสาร

Module 1 ไม่มีคำสั่งดาวน์โหลดหรือติดตั้งซอฟต์แวร์จากภายนอก ผู้เรียนต้องใช้ Workspace
ที่เตรียมไว้ในเครื่องหรือผ่านช่องทางภายในที่ได้รับอนุมัติ
