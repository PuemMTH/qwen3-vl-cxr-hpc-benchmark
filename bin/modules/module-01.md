## รู้จัก Terminal / CLI

### Terminal คืออะไร?

Terminal คือช่องสำหรับบอกคอมพิวเตอร์ให้ทำงานด้วยข้อความ ส่วน CLI หรือ Command-Line Interface คือโปรแกรมที่เราเรียกใช้ผ่านช่องนี้ หนึ่งบรรทัดคือหนึ่งคำสั่ง ในกิจกรรมนี้ไม่ต้องจำคำสั่งและไม่ต้องพิมพ์เอง—อ่านก่อน กด Copy วาง แล้วกด Enter

Windows 11

#### เปิด PowerShell แบบปกติ

1. กดปุ่ม

   **Windows**

   บน keyboard หรือคลิก Start
2. พิมพ์

   **PowerShell**
3. คลิก

   **Windows PowerShell**

   หรือกด Enter
4. ตรวจ title bar ต้องไม่มีคำว่า

   **Administrator**

พร้อมเมื่อเห็น `PS C:\Users\ชื่อผู้ใช้>`

ตัวอย่าง PowerShell

`PS C:\Users\student> ▌`

**PS** = PowerShell · **C:\Users\student** = โฟลเดอร์ปัจจุบัน · **▌** = จุดวางคำสั่ง

- **Paste:**

  Ctrl+V
- **Run:**

  กด Enter แล้วรอจนเห็น

  `PS ...>`

  กลับมา
- **Stop:**

  กด Ctrl+C แล้วเรียกผู้สอน
- **Safety:**

  อ่านก่อนรัน และไม่วาง password/token

macOS

#### เปิด Terminal

1. กด

   **Command (⌘) + Space**
2. พิมพ์

   **Terminal**
3. เลือกแอป Terminal แล้วกด Enter
4. ใช้หน้าต่างปกติ ไม่พิมพ์

   `sudo`

   ในขั้นนี้

พร้อมเมื่อเห็นชื่อเครื่องตามด้วย `%` หรือ `$`

ตัวอย่าง macOS Terminal (zsh)

`student@MacBook ~ % ▌`

**student@MacBook** = ผู้ใช้และชื่อเครื่อง · **~** = home folder · **%** = พร้อมรับคำสั่ง

- **Paste:**

  Command (⌘)+V
- **Run:**

  กด Enter แล้วรอจนเห็น

  `%`

  หรือ

  `$`

  กลับมา
- **Stop:**

  กด Control+C แล้วเรียกผู้สอน
- **Safety:**

  อ่านก่อนรัน และไม่วาง password/token

Linux / WSL2

#### เปิด Terminal หรือ Ubuntu

1. Linux: เปิดแอป

   **Terminal**
2. WSL2: กด Start แล้วเปิด

   **Ubuntu**
3. รอจนเห็นบรรทัด prompt
4. ยังไม่พิมพ์

   `sudo`

   ในขั้นนี้

พร้อมเมื่อเห็นชื่อผู้ใช้และเครื่องตามด้วย `$`

ตัวอย่าง Linux / WSL2 Terminal

`student@ubuntu:~$ ▌`

**student@ubuntu** = ผู้ใช้และชื่อเครื่อง · **~** = home folder · **$** = พร้อมรับคำสั่ง

- **Paste:**

  Ctrl+Shift+V
- **Run:**

  กด Enter แล้วรอจนเห็น

  `$`

  กลับมา
- **Stop:**

  กด Ctrl+C แล้วเรียกผู้สอน
- **Safety:**

  อ่านก่อนรัน และไม่วาง password/token

## เตรียม Workspace ที่มีอยู่แล้ว

Core Program ไม่ดาวน์โหลดหรือติดตั้งซอฟต์แวร์จากภายนอก ให้ใช้ Workspace ที่องค์กร ผู้สอน หรือผู้เรียนเตรียมไว้ในเครื่องก่อนเริ่ม โดยตรวจว่ามีองค์ประกอบต่อไปนี้:

- AI workspace ที่เลือก: Codex, Claude Code หรือ Antigravity
- โปรแกรมอ่านและแก้ไข Markdown
- เครื่องมือสร้างและเปิด PDF
- เครื่องมือนำเข้าเอกสารและ OCR ไทย–อังกฤษ เมื่อจะทำ Module 2
- โฟลเดอร์ `input/original/`, `input/markdown/`, `output/` และ `profile/`

หากเครื่องยังไม่มีองค์ประกอบเหล่านี้ ให้หยุดและเตรียมระบบผ่านช่องทางภายในที่ได้รับอนุมัติก่อนดำเนินบทเรียนต่อ

## ตรวจว่า Workspace เปิดแล้ว

หากเห็นโฟลเดอร์งานใน VS Code หรือ Antigravity IDE แล้ว ไม่ต้องเปิดซ้ำ ให้ไปที่ “เชื่อมต่อบัญชี AI” ได้เลย วิธีด้านล่างใช้เมื่อปิดหน้าต่างไปแล้วหรือต้องการเปิดใหม่เท่านั้น

### Workspace ไม่เปิดอัตโนมัติ? ดูวิธีเปิดใหม่

Windows 11

#### เปิดด้วย PowerShell

1. เปิด PowerShell แบบปกติ
2. คัดลอกคำสั่งด้านล่างแล้วกด Enter
3. รอให้

   VS Code

   เปิดโฟลเดอร์งาน

```text
code --profile "AI for Research - {agent}" "$HOME\ai-for-research-workspace"
```

#### เปิดผ่าน Antigravity IDE

1. เปิด Antigravity จาก Start menu และ Sign in ด้วยบัญชี Google
2. เลือก

   **File → Open Folder**
3. วาง path ด้านล่าง แล้วกด

   **Select Folder**

```text
%USERPROFILE%\ai-for-research-workspace
```

ถ้า PDF Viewer ยังไม่มี ให้เปิด Extensions ใน IDE แล้วติดตั้ง `mathematic.vscode-pdf`

macOS

#### หาก Workspace ยังไม่เปิด

1. เปิด VS Code
2. กด

   **Command (⌘) + O**
3. กด

   **Command (⌘) + Shift + G**
4. วางตำแหน่งโฟลเดอร์ด้านล่าง กด Enter แล้วกด

   **Open**

```text
~/ai-for-research-workspace
```

#### หาก Antigravity Workspace ยังไม่เปิด

1. เปิด

   **Terminal**

   ไม่ใช่ช่องค้นหาโฟลเดอร์ใน Antigravity
2. คัดลอกคำสั่งด้านล่างแล้วกด Enter
3. รอให้ Antigravity IDE เปิดโฟลเดอร์งาน

```text
agy-ide "$HOME/ai-for-research-workspace"
```

Linux / WSL2

#### เปิดด้วย Terminal

1. เปิด Terminal หรือ Ubuntu/WSL2
2. คัดลอกคำสั่งด้านล่างแล้วกด Enter
3. รอให้

   VS Code

   เปิดโฟลเดอร์ผ่าน Linux/WSL2

```text
สำหรับ Codex หรือ Claude Code:
code --profile "AI for Research - {agent}" "$HOME/ai-for-research-workspace"

สำหรับ Antigravity:
agy-ide "$HOME/ai-for-research-workspace"
```

### เชื่อมต่อบัญชี AI

เลือกเฉพาะเส้นทางที่ตรงกับเครื่องมือของคุณ:

- **Codex:** เปิด Codex panel ใน VS Code เลือก **Sign in with ChatGPT** ยืนยันใน Browser แล้วกลับมาที่ VS Code
- **Claude Code:** เปิด Claude Code panel ใน VS Code เลือกบัญชี Claude App หรือ Anthropic Console ตามสิทธิ์ ยืนยันใน Browser แล้วกลับมาที่ VS Code
- **Antigravity:** เปิด Antigravity IDE กด **Sign in** ด้วยบัญชี Google แล้วเลือก Theme และ **Review-driven development** เมื่อระบบถามนโยบายการทำงาน

> **พร้อมไปต่อเมื่อ:**
>
> Sign in สำเร็จและเห็นช่องสนทนาใน AI panel

### ฝึกบอกบริบทของคุณให้ AI

กิจกรรมนี้ฝึกให้ AI รู้ว่าใครกำลังทำงานอะไรและต้องการความช่วยเหลือแบบใด โดยให้ข้อมูลเท่าที่จำเป็น ช่องที่ไม่เกี่ยวข้องข้ามได้ และไม่ต้องระบุรหัสนิสิต เบอร์โทร อีเมล ที่อยู่ credential หรือข้อมูลส่วนบุคคลของผู้อื่น

> AI ถามทีละข้อ ไม่เดาข้อมูล รอการอนุมัติก่อนสร้างไฟล์ ผู้เรียนเปิดและตรวจข้อมูลทั้งสามไฟล์ได้ และทราบว่าโมดูลถัดไปจะอ่านข้อมูลเหล่านี้เป็นบริบทเพิ่มเติม ส่วน BibTeX เป็นเพียงไฟล์ข้อมูลผู้แต่งที่เลือกสร้างเมื่อจำเป็น

### ทดลองไฟล์ Markdown แรก

1. **เปิดและแก้ Markdown**

   คลิก

   `content.md`

   แล้วแก้ข้อความตัวอย่าง
2. **ดู Markdown Preview**

   กด Ctrl+Shift+V (macOS: Command+Shift+V) เพื่อดูผลลัพธ์ที่จัดรูปแบบแล้ว
3. **ให้ AI อ่านและสร้าง PDF**

   วาง prompt ด้านล่างใน

   AI panel ของเครื่องมือที่เลือก

   ; agent จะอ่านคำสั่งใน Workspace และใช้ Integrated Terminal เบื้องหลังเมื่อจำเป็น

   ```text
   อ่าน content.md แล้วสร้าง output/content.pdf ตามรูปแบบที่กำหนดไว้ใน Workspace โดยไม่เปลี่ยนไฟล์ต้นฉบับ จากนั้นตรวจว่าไฟล์ PDF สร้างสำเร็จ
   ```
4. **อนุญาตเฉพาะ Pandoc**

   หาก IDE ถาม

   _Allow running this command?_

   ให้เลือก

   **Yes, and always allow “pandoc”**

   สำหรับ Workspace ของรายวิชานี้ ไม่เลือกอนุญาต shell หรือทุกคำสั่งแบบกว้าง
5. **เปิด PDF**

   คลิก

   `output/content.pdf`

   และตรวจว่าเปิดอ่านได้ เป็นกระดาษ A4 ภาษาไทยใช้ Sarabun จาก Google Fonts ที่ติดตั้งพร้อม Workspace และมีรูปแบบสีตาม template

- [ ] AI ถามข้อมูลทีละข้อและรอฉันอนุมัติก่อนสร้างไฟล์
- [ ] เปิดและตรวจ `profile/learner-profile.yaml`, `profile/learner-profile.md` และ `profile/learning-context.md` แล้ว

- [ ] เปิด อ่าน แก้ และ Preview `content.md` ได้

### เริ่มต้นใหม่หลังติดตั้ง

1. **เปิด Terminal**

   Windows เปิด PowerShell; macOS เปิด Terminal; Linux/WSL2 เปิด Terminal หรือ Ubuntu
2. **เข้าโฟลเดอร์ Workspace**

   ใช้

   `cd`

   ไปยังโฟลเดอร์งานที่ installer สร้างไว้
3. **เปิด Workspace**

   รัน

   `code .`

   เพื่อเปิด

   VS Code

   ```text
   สำหรับ Codex หรือ Claude Code:
   cd "$HOME/ai-for-research-workspace"
   code .

   สำหรับ Antigravity:
   cd "$HOME/ai-for-research-workspace"
   agy-ide .
   ```

Checkpoint

## จบบทเรียน

เปิดซ้ำด้วยตัวเองและตรวจว่าพร้อมใช้ในโมดูลถัดไป

### ทบทวน

ปิดแล้วเปิด Workspace ใหม่ และยืนยันว่า AI panel, Markdown, PDF และโฟลเดอร์งานยังทำงาน

### หากต้องการความช่วยเหลือ

เก็บข้อความที่เห็นบนหน้าจอหรือถ่ายภาพไว้ แล้วนำมาถามผู้สอนในชั้นเรียน

### เตรียมเอกสารก่อนมาเรียน

เลือกเรื่องที่สนใจ แล้วเตรียมข่าว รายงาน บทความ หรือบทวิจารณ์ 6–8 ชิ้น รวมประมาณ 15–20 หน้า เก็บไว้ใน `input/original/` โดยต้องเป็นข้อมูลที่นำมาใช้กับ AI ได้

> **พร้อมมาเรียนเมื่อ:**
>
> เปิด Workspace ได้ คุยกับ AI ได้ อ่าน Markdown และ PDF ได้ และเตรียมเอกสาร 6–8 ชิ้นไว้ใน
>
> `input/original/`
>
> แล้ว
