## เนื้อหาพูดแบบสั้น (ประมาณ 6–8 นาที)

1. **ทวนโจทย์:** “ครั้งก่อนเรานำเสนอแผนใช้ Qwen3-VL จำแนกภาพ Chest X-ray เป็น NORMAL หรือ PNEUMONIA และถามว่า A100 บน LANTA ช่วยเรื่องความจุ ความเร็ว และคุณภาพหรือไม่”
2. **Current Experimental Setup:** “ทวนโจทย์ pediatric CXR สองคลาส โมเดล Qwen3-VL 2B/4B/8B เครื่อง RTX 5070 กับ A100 และตัวชี้วัดความถูกต้อง เวลา throughput, GPU memory และ scalability Set A ใช้ภาพ พรอมป์ model revision และ config hash ตรงกัน แต่ RTX ใช้ Python 3.12.13 / PyTorch 2.14.0+cu130 ส่วน A100 ใช้ Python 3.11.10 / PyTorch 2.7.1+cu126 จึงเป็นการเทียบทั้งแพลตฟอร์ม”
3. **Batch คืออะไรและทำไมเพิ่ม:** “Batch 1 คือหนึ่งคู่ภาพ–พรอมป์ (prompt) ส่วน batch 2 คือสองคู่ภาพ–พรอมป์ที่ใช้ข้อความพรอมป์เดียวกันและประมวลผลพร้อมกัน จึงได้คำตอบแยกสองรายการ ภาพทั้งสองไม่จำเป็นต้องเป็นคลาสเดียวกัน เมื่องานมี 1,000 ภาพ การเรียกโมเดลลดจาก 1,000 ครั้งที่ batch 1 เป็น 500 ครั้งที่ batch 2, 250 ครั้งที่ batch 4 และ 125 ครั้งที่ batch 8 เราทดลองเพื่อดูว่าภาพต่อชั่วโมงดีขึ้นเท่าไร โดยวัดเวลาต่อ batch และหน่วยความจำ GPU ด้วย”
4. **พรอมป์ที่ใช้จริง:** “พรอมป์มีสี่ส่วน: ให้จำแนก NORMAL/PNEUMONIA, ตอบเป็น JSON, ใช้ UNCERTAIN เมื่อภาพไม่พอ และไม่เพิ่มคำอธิบาย ข้อความเดียวกันใช้กับทุกภาพ โดยได้คำตอบแยกกัน”
5. **ข้อมูลที่ใช้ทดสอบ:** “รอบนี้ใช้ภาพเอกซเรย์ทรวงอกจาก Mendeley V3 โดยไม่ได้ฝึกโมเดล A ใช้เทียบเครื่อง B ดูความถูกต้อง ส่วน C แบ่งสองขั้น: C1 เพิ่มภาพต่อครั้งบน GPU ใบเดียวจาก 1 ถึง 8 ภาพ แล้วเลือก batch 8 ไปใช้ใน C2 เพื่อทดสอบ GPU 1, 2 และ 4 ใบบนงานคงที่”
6. **เวลาที่ใช้ประเมิน:** “ผลความเร็ว A/C ใช้ผลรวมเวลา pipeline ของ batch ที่สำเร็จหลัง warm-up เริ่มก่อนเปิดภาพ แล้วอ่านและปรับภาพ เตรียมภาพกับพรอมป์ ส่งเข้า GPU สร้างคำตอบ และ decode/parse จนได้ผล ไม่รวมเวลาโหลดโมเดลหรือรอคิว C2 ใช้เวลาของ GPU ที่ช้าที่สุดในแต่ละรอบแล้วหามัธยฐาน 5 รอบ ส่วน B ประเมินความถูกต้องจากคำทำนายเทียบคำตอบอ้างอิง ไม่ได้ใช้เวลามาคิดคะแนน”
7. **Experiment A:** “เวลาในสูตรอัตราส่วน A100 เทียบ RTX คือ pipeline ที่เริ่มจับก่อนเปิดภาพจากดิสก์และจบหลัง decode/parse คำตอบเสร็จในแต่ละ batch แล้วรวมเฉพาะ batch ที่สำเร็จหลัง warm-up ไม่รวมโหลดโมเดลหรือรอคิว ตัวอย่าง 4B รอบ 3: RTX 5070 ใช้ generate 212.803 วินาที และขั้นตอนอื่นรวม 18.778 วินาที ได้ pipeline 231.581 วินาที; A100 ใช้ 304.437 + 24.782 = 329.219 วินาที หารเวลา RTX ด้วยเวลา A100 ในรอบเดียวกันแล้วหามัธยฐานอัตราส่วน 5 รอบ จึงได้ 0.703 เท่า ตารางแสดงเวลาของรอบที่ให้อัตราส่วนค่ากลาง ไม่ใช่มัธยฐานเวลาแยกเครื่อง ไม่ได้จับเวลาแยกในแต่ละขั้นตอนอื่น”
8. **กราฟ A:** “เมื่อแปลงเป็นภาพต่อชั่วโมง ที่ batch 1 RTX ทำได้มากกว่า A100 ใน 2B, 4B และ 8B NF4 ภายใต้เงื่อนไขแพลตฟอร์มที่ทดสอบ”
9. **Experiment B:** “Balanced accuracy คือค่าเฉลี่ยอัตราตอบถูกของสองคลาส; ค่า RTX และ A100 ใกล้กันในสามแบบที่รันได้ทั้งสองเครื่อง แต่คำทำนายรายภาพไม่เหมือนกันทุกภาพ: 2B ต่าง 17 จาก 600 ภาพ, 4B ต่าง 11 จาก 600 ภาพ และ 8B NF4 ต่าง 19 จาก 600 ภาพ ผล RTX คัดจาก A บนภาพเดียวกันและ config hash ตรงกับ A100 A; ผล A100 A ตรงกับ B ทุกภาพ สาเหตุความต่างยังต้องตรวจ ไม่เดา 8B BF16 มีผลเฉพาะ A100 ค่า balanced accuracy 44.17% และ UNCERTAIN 32.67%”
10. **Experiment C:** “C1 ใช้เวลา pipeline เดียวกันเป็นตัวหารของภาพต่อชั่วโมง: 4B BF16 เพิ่มจาก 10,894 เป็น 41,614 ภาพต่อชั่วโมงที่ batch 8 ส่วน C2 ใช้เวลา pipeline ของ GPU ที่ช้าที่สุดต่อรอบแล้วหามัธยฐาน 5 รอบ งานคงที่ 2,000 ภาพเมื่อเพิ่ม GPU เป็น 2/4 ใบเร็วขึ้น 1.99/3.91 เท่า ไม่ได้ใช้ complete-round wall หรือเวลารอคิวในสูตร”
11. **จุดที่ A100 สูงกว่าค่า RTX batch 1:** “กราฟใช้ RTX 5070 batch 1 จาก A ที่ 15,545 ภาพต่อชั่วโมงเป็นค่าอ้างอิง เมื่อ A100 หนึ่งใบเพิ่มเป็น batch 2 ใน C1 ได้ 17,476 ภาพต่อชั่วโมง จึงสูงกว่าค่าอ้างอิง 1.12 เท่า แต่เรายังไม่มีผล RTX ที่ batch 2/4/8 และสองชุดนี้เป็นคนละรอบทดลอง”
12. **สรุปตาม Need:** “capacity และ throughput แบบ batch/หลาย GPU มีหลักฐานรองรับ ส่วนคุณภาพบนภาพเดียวกันของ RTX/A100 ใกล้กันแต่คำทำนายรายภาพต่างกัน 17/11/19 จาก 600 ภาพ สาเหตุยังค้าง ผลทั้งหมดเป็น Development/Pilot ยังไม่ใช่ผลยืนยันหรือหลักฐานเชิงคลินิก”

## จุดที่ต้องไม่สื่อเกินผล

- ตัวเลข pilot เก่า 20 ภาพ, Set A 1,000 ภาพ, Set B 600 ภาพ และ Set C2 2,000 ภาพ เป็นคนละการวัด ใช้ metric และตัวหารให้ถูกชุด
- ความเร็ว A100 ใน Set A เป็นการเทียบแพลตฟอร์มที่ software stack ต่างกัน; ไม่สรุปสาเหตุว่า GPU รุ่นหนึ่งช้ากว่าโดยตัวมันเอง
- กราฟจุดแซงใช้ RTX 5070 batch 1 เป็นค่าอ้างอิงเทียบกับ A100 จาก C1 ซึ่งเป็นคนละรอบทดลอง; ยังไม่มีผล RTX batch 2/4/8 ที่จะเทียบในเงื่อนไข batch เท่ากัน
- ยังไม่มี output tokens/sec ที่สรุปเป็นผล, ไม่มี end-to-end turnaround, ไม่มี CI ของ C2 และไม่มี confirmatory Test result
- ผลทำนายรายภาพ RTX/A100 ต่างกัน 17/11/19 ภาพในสามแบบที่เทียบได้; config hash และ model revision ของ A ตรงกัน แต่ยังไม่พิสูจน์สาเหตุ และยังไม่มี local B run โดยตรง
